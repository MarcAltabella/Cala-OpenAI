---
name: flowcharts
description: Create or update process flowcharts for software systems and workflows using Mermaid.
---

Use Mermaid for every flowchart. Write diagrams as Mermaid `flowchart` syntax so agents and engineers can inspect, render, and revise the design consistently.

- Identify the process boundaries, inputs, decisions, actions, outputs, and failure paths.
- Keep node labels concise and make branch conditions explicit.
- Prefer a readable direction such as `TD` or `LR`, and split overly large diagrams into focused subflows.
- Include the Mermaid source in the relevant design artifact or documentation, alongside a short explanation when useful.
- Follow the [Mermaid flowchart syntax](https://mermaid.js.org/syntax/flowchart.html) for supported syntax and rendering details.
