---
name: sequence-diagrams
description: Create or update software interaction sequence diagrams using Mermaid.
---

Use Mermaid for every sequence diagram. Write diagrams as Mermaid `sequenceDiagram` syntax so agents and engineers can inspect, render, and revise the interaction design consistently.

- Identify the participants, their responsibilities, and the order of messages.
- Show synchronous calls, asynchronous messages, returns, decisions, loops, errors, and alternate paths when they affect the behavior.
- Keep participant and message labels concise; use notes or grouping to clarify important boundaries.
- Include the Mermaid source in the relevant design artifact or documentation, alongside a short explanation when useful.
- Follow the [Mermaid sequence diagram syntax](https://mermaid.js.org/syntax/sequenceDiagram.html) for supported syntax and rendering details.
