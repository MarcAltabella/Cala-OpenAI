---
name: branch-naming
description: Define and apply a repository-compliant branch name before beginning implementation work.
---

Use when starting implementation, creating a branch, or making a plan that will lead to code changes.

Determine the repository's username and branch convention from the active project profile or repository context. For the Ehub convention, use `{username}/eng-{n}-{short-slug}`, where `n` is the next unused Engineering Hub number and the slug is two to four lowercase kebab-case words. Confirm the branch name and base branch before changing code. Continue on an existing active branch rather than creating a second branch for the same change.
